# Karat Java Coding Practice

This workspace contains starter problems based on the Citi/Karat coding files.

The files are intentionally not solved. Each package gives you:

- a small domain model
- raw sample data
- TODO methods for you to implement
- comments explaining what the problem asks

## Suggested Order

Start with the easiest problems first.

1. `paymenttransactions`
   - balance by account
   - average transaction amount by account
2. `gymmembership`
   - member statistics
   - average workout duration
   - due payment calculation
3. `stockprices`
   - min, max, average
   - biggest price change after sorting by date
   - current, maximum, minimum with timestamp corrections
4. `musicstreaming`
   - listener statistics
   - duplicate song grouping
5. `fooddelivery`
   - order statistics
   - average delivery time by restaurant
6. `clinicappointments`
   - appointment statistics
   - average visit duration by type
7. `obstaclecourse`
   - personal best
   - best of best segment times
   - chance of personal best using simulation
8. `tollboothlogs`
   - parse logs
   - count complete journeys
   - calculate speed between road sensors

## How To Practice

Open one package at a time.

For each problem:

1. Read the model classes.
2. Understand the raw data.
3. Implement the TODO methods.
4. Run or mentally verify with the expected output comments.
5. Send me your solution and I will review it.
